# Generador TET - Análisis de Círculos

Aplicación interactiva desarrollada en **React + TypeScript + Vite** para generar y visualizar círculos TET (temperamento igual dividido).

## 🚀 Ejecución local

```bash
npm install
npm run dev
```

Luego abre en tu navegador:  
👉 http://localhost:5173

---

## 🧱 Compilar versión de producción

```bash
npm run build
```

Los archivos finales se guardan en la carpeta `dist/`.

---

## 🌐 Desplegar en GitHub Pages

1. Crea un nuevo repositorio en GitHub llamado **generadorTETAnalisisCirculos**
2. Ejecuta:

```bash
npm run deploy
```

Esto publicará automáticamente tu sitio en la rama `gh-pages`.

Luego activa GitHub Pages desde:  
`Settings → Pages → Source → Deploy from branch → gh-pages`

Tu app quedará disponible en:  
👉 https://<TU_USUARIO>.github.io/generadorTETAnalisisCirculos/
